tutor–tutee matching.

I developed a Python-based tool to pair tutors and students using subject, availability, and preference constraints within a community mentorship program.

  • Python
  • Constraints
  • Program operations

Contribution Translating an operational need into a repeatable matching workflow.

The practical problem

Tutor–tutee pairing needs to account for subject needs, overlapping availability, and preferences. I developed and implemented a Python tool to organize these requirements within the Saturday Program.

What this demonstrates

Turning program requirements into computational constraints, connecting technical work to day-to-day coordination, and building a tool for a community setting.

Program context

The Saturday Program supports marginalized high-school students interested in health-care careers. My technical contribution sat alongside leadership responsibilities in recruitment, training, and program coordination.
