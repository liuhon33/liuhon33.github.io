Independent study · Interactive learning

Deep Learning Lab.

I build visual experiments to connect neural-network equations with the behaviour of features, gradients, and predictions. The first lab compares plain and residual networks as they learn the same function.

  • JavaScript
  • Neural networks
  • Data visualization
  • Experiment design
What this work demonstrates

Turning abstract learning mechanisms into experiments you can pause, inspect, and change.

A visible mechanism

The motivation

From an equation to something I can investigate.

I wanted to understand what happens inside a network while it learns: how inputs become features, how a prediction changes, and how learning signals travel backward. Building an interactive lab lets me connect those questions to a model I can inspect.

The approach

One model state. Several connected views.

Each experiment links the input, internal representations, predictions, loss, and gradients. I can pause training, follow the same input through the network, and change one factor to see what happens.

    The project

    A comparison you can watch.

    Why can deeper networks become harder to train, and what does a shortcut change? This browser lab compares a plain network with a residual network learning the same landscape, making their progress visible as they train.

    What I built

    Connected views, hands-on controls.

    I built linked feature maps, prediction surfaces, loss curves, and gradient plots. You can pause training, follow one input through the network, and inspect or change individual weights to test an idea.

    Screenshots from one visualizer run: 36 blocks · 10 features per layer · seed 7 · 500 updates.
